# P1 持久化协作核心验证

日期：2026-10-30。实际运行环境：Windows amd64、Go 1.25.0、Google Chrome。所有数据测试使用独立临时工作区。

## 当前实现

- Go 标准库 HTTP 服务、共享密码与随机密码、8 小时会话、同源写入与 WS、旧 buildId 拒绝。
- CWD 工作区文件锁、实际 Markdown 枚举、原文件名创建和页面路径。
- 唯一初始化者及资格转交；官方编辑器与纯 Go Yjs V1 协作，Awareness 仅更新本连接控制的 client ID。
- 每次更新候选状态完整快照成功后才广播确认，独立 revision；Markdown 三步原子投影与中断恢复。
- 已打开笔记断线时继续本地编辑，未确认更新留在页面内存，持续重连与幂等重发。同会话重连接管半开的旧 socket，其他会话不能接管该 client ID。
- 外部修改/更名停止旧房间，孤立快照不复活文件；明确创建新文件会先重置同名孤立状态。
- 内部错误传递到主进程 fatal 通道，停止服务并非零退出。
- Vite 生成构建身份与资源，Go embed 正式分发。

## Go 测试

`go test ./...` 覆盖：

- 快照已提交、Markdown 已替换两种中断状态的恢复。
- 外部正文变更、文件更名、旧地址不复活、孤立状态后显式创建。
- 工作区排他锁、损坏快照拒绝、路径穿越与非法文件名。
- 纯删除不改变 state vector 时仍递增 revision，旧 flush 被拒绝。
- 快照替换失败不推进内存状态、不广播确认。
- 初始化者离开后只向一个等待者转交资格。
- 多 goroutine 提交串行化、修订广播有序和已确认快照持久化。
- Windows 并发读取与投影回归：8 个页面读取者与 100 次原子投影并发运行。修复前稳定复现本程序自己的读取阻挡替换；内部读写协调后通过，不增加重试，不吞掉外部写入错误。
- 不消费慢连接有限发送队列，连续提交 65 次更新后明确取消慢连接；正常成员确认和持久化不受影响，慢成员重连得到包含全部提交的最新快照。此项在房间层并通过 race 检查，尚不等同于所有真实网络背压场景。

## 浏览器和真实进程

`web/tests/p1.spec.ts` 覆盖两个隔离浏览器同时打开已有中文笔记、编辑收敛和实际保存；只读预览、在线成员、带空格路径、新建冲突、未登录访问、旧构建拒绝、延迟 saved 确认不阻塞后续投影，以及丢失 update 确认后继续编辑、自动重连/重发且内容不重复。另验证空段落同步、远端修改后光标续写、长文选区和滚动位置保留，以及中文组合输入并发编辑。

后续新增同段中文删除与 emoji 插入、本地撤销/重做不影响远端内容、成员退出光标移除，以及 Chromium 组合输入管线测试。实际范围与事件记录见 [原生输入验收](NATIVE_INPUT.md)。

`web/tests/process.spec.ts` 启停真实 `lannoto.exe`，覆盖：

1. CRDT 比 Markdown 新时终止进程，重启并重新登录恢复该内容并完成实际 Markdown 写回。
2. 将正式快照目标替换为目录注入真实替换失败，进程非零退出，磁盘 Markdown 无未确认内容，页面不报告已保存。
3. 省略密码、显式空密码均生成随机密码，日志只显示一次且可登录；两次启动密码不同，旧密码/旧会话失效，config 不公开密码；显式密码不出现在日志。
4. 在线外部覆盖使房间停止，服务重启后使用磁盘新正文，不重播旧快照。
5. 在线更名后列表显示新名，旧页面停止、旧路径 404，打开新路径仍有实际正文，旧文件不复活。
6. 第二个真实进程不能获取同一工作区锁；正式快照损坏时真实启动非零退出，不改写正文或损坏快照。
7. 真实进程停止后修改 Markdown，重新启动后正文与恢复快照均使用实际新内容。
8. Windows 辅助进程以只读且不共享删除的真实句柄占用 Markdown。编辑后，三步投影的首个快照已记录新正文与旧 diskHash，Markdown 替换失败使正式服务非零退出，不发 saved；解除占用后重启，真实正文与 diskHash 完成恢复，内容不重复。

Go race 已通过：使用测试目录中的便携 LLVM-MinGW 20261020、`CGO_ENABLED=1` 和 `CC=x86_64-w64-mingw32-clang.exe` 执行 `go test -race ./...`。工具链下载摘要与官方发布 SHA256 相符；没有安装到系统或修改永久 PATH。

后续加入的确定性故障构建还覆盖 Write/Sync 错误，以及首个投影快照提交后、Markdown 替换后两个真实进程中断状态。普通和故障标签构建均通过 race 检查；完整范围见 [持久化故障验收](PERSISTENCE_FAULTS.md)。
