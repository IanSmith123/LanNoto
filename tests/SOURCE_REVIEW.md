## 检查后保留的机制

- Markdown 是唯一协作与落盘正文；来源模式之间不另存富文本权威状态。
- 普通断线保持源码和所见即所得可编辑，页面内存保留未确认增量，持续重连并合并、幂等重发。已打开文档无需手动重连；Ctrl+S 等待恢复后保存与留档。页面关闭后恢复未同步内容不在当前保证内。
- 路径根限制、同源与会话校验、有界输入/发送队列、先持久化再确认、摘要冲突检测、原子替换、完整性校验、取消及清理错误传播属于必要约束，继续保留。
- 操作系统专用文件同步和替换代码属于平台实现；独立故障标签只用于测试，发布程序不含故障控制。
- Milkdown/Crepe 及其依赖源码未修改，没有私有 API 或旧版本探测分支。

修复了两类故障：

- 重连、上传或导出收到 HTML、纯文本或空的 HTTP 错误响应时，原实现会因 JSON 解析失败触发编辑器 fatal。接口与下载现共用状态码和业务错误处理，502/503/504 的重连失败继续等待重试，操作错误显示状态码，不停止正常编辑。
- 会话过期原先直接销毁编辑器并显示登录页，可能丢失页面内尚未确认的改动。现在保留编辑器、协作文本、待确认队列和等待保存的请求，在原页面重新认证；输错密码可以重试，取消后仍可本地编辑，通过「重新连接」再次登录并同步。

新增四项浏览器回归，覆盖 HTML 503 重连、纯文本 502 打包失败、重连发现会话过期、刷新列表发现会话过期。会话测试拦截尚未发送到服务器的更新，实际清除登录 Cookie，验证错误密码、取消、续写、Ctrl+S、重新登录及重载后的正文保留。
