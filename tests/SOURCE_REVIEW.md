## 检查后保留的机制

- Markdown 是唯一协作与落盘正文；来源模式之间不另存富文本权威状态。
- 普通断线保持源码和所见即所得可编辑，页面内存保留未确认增量，持续重连并合并、幂等重发。已打开文档无需手动重连；Ctrl+S 等待恢复后保存与留档。页面关闭后恢复未同步内容不在当前保证内。
- 路径根限制、同源与会话校验、有界输入/发送队列、先持久化再确认、摘要冲突检测、原子替换、完整性校验、取消及清理错误传播属于必要约束，继续保留。
- 操作系统专用文件同步和替换代码属于平台实现；独立故障标签只用于测试，发布程序不含故障控制。
- Milkdown/Crepe 及其依赖源码未修改，没有私有 API 或旧版本探测分支。
